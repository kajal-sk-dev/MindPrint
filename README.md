> Your code has a MindPrint. AI can't fake it.

A human-centric AI platform to detect AI-generated content and verify human authenticity — built for recruiters, educators, and originality.

## 🌟 Features
- 🧠 MindPrint Detection - Distinguishes human vs AI code/writing
- 📊 Authenticity Score - Confidence analysis
- 🎯 Proof of Thought - Blockchain-ready human verification
- 🔒 Private & Secure - Local analysis

## 🚀 Tech Stack
- **Frontend:** Streamlit
- **Backend:** Python
- **AI:** LLM Detection + RAG
